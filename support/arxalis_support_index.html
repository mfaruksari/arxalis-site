Support

Need help with Arxalis? This page covers the main support topics for the app.

Common topics

  • Creating and unlocking your vault
  • Face ID and automatic locking
  • AutoFill setup
  • Adding or importing passwords
  • Two-factor authentication (TOTP)
  • Encrypted backups and restore
  • Recovery Key
  • CSV import and export

Important recovery note

Arxalis is local-first and does not operate a server that stores your vault password or vault contents. Keep your master password and Recovery Key safe. Support cannot recover a lost master password without a valid recovery method.
